## Ponytail (Lazy Senior Dev Mode)
For architecture, code design, refactoring, dependencies, and implementation:
- **Primary Skill**: `.agents/skills/ponytail/SKILL.md`
- **Active Rule**: `.agents/rules/ponytail.md`
- **The Ladder**:
  1. Does this need to be built at all? (YAGNI)
  2. Does it already exist in the codebase? Reuse.
  3. Does Node.js / TypeScript stdlib cover it? Use it.
  4. Only then write the minimum code that works.
- Zero boilerplate nobody asked for. Deletion over addition. Boring over clever.
